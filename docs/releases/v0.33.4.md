# v0.33.4 — Faster sample loading

The Samples page previously performed per-row permission and linked-project queries,
and reloaded reference data on each search keystroke, filter and page change.

- Compute display permissions in SQL and consume ordered linked-project prefetches.
- Load projects, containers, user and sample forms once per page visit.
- Debounce search by 250 ms, abort obsolete requests and reset pagination with filters.
- Add query-growth, permission and browser request-lifecycle regression coverage.

Local SQLite benchmark: 50 samples use 9 SQL queries instead of 207; p95 decreases
from 74.42 to 17.85 ms with 1,000 samples/work items and 20 warm rounds. These are
local API measurements, not production concurrency or capacity guarantees.

Validation: 10 sample tests, 5 opt-in performance scenarios, the browser loading
regression, targeted ESLint and the production frontend build. Backend tests use
SQLite with --nomigrations; PostgreSQL migration/CI validation remains separate.

No schema migration or new configuration is required. Deploy backend and frontend
together using the normal update procedure.
