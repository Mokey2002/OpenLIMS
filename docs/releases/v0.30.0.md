# v0.30.0 — Configurable laboratory workflows

## Included

This version groups the recent installer/form work and adds measurement-based activation rules:

- Guided production installer foundation, secure configuration and diagnostics (PR #101).
- Versioned bilingual sample form builder (PR #102).
- Audited sample-value editing, CSV preview/confirmation/export, richer controls and JSON templates (PR #103).
- Published measurement forms attached and pinned to workflow steps, completion validation and retry audit (PR #104).
- Measurement activation rules and a read-only example preview using the same typed comparison
  as execution. Rules select a source dependency's pinned form key and EQ, NE, GT, GTE, LT, LTE
  or IN. Numeric thresholds must be finite, ordered comparisons require numbers, and dropdown
  values must be defined options. IN accepts a comma-separated list or JSON array.
- Evaluation audit events contain the pinned condition, source step/form revision, observed
  value and decision. Existing runs keep copied conditions; template edits affect new runs.

## Example: concentration routing

Attach a measurement form containing numeric `concentration` to step 1. Configure step 2 with
dependency 1, source Form measurement, field concentration, LT, 10; this may be a review procedure
with QC required. Configure step 3 with dependency 1, GTE, 10 for processing. Each condition is
evaluated after its dependencies finish. A nonmatching branch is skipped, not failed. Missing
values do not activate either branch. Make source measurements required when a routing decision
must be guaranteed. Existing result-based rules retain their legacy behavior.

Preview only evaluates the selected comparison; it does not execute steps, publish configuration,
approve QC or simulate a complete DAG. No arbitrary code or expressions are executed.

## Scope and deployment gates

The rule acts on step activation. Automatic team assignment, notification rules, conditional
QC policy changes, loop creation, generic cross-module rules and complete lab setup bundles are
not included. A review/repeat branch must be modeled as an explicit procedure/step. Existing
retry limits and QC settings remain in control.

The release does not certify production readiness. Run PostgreSQL migrations, concurrency tests,
full CI, browser workflows and restore validation before deployment. Local tests use an isolated
SQLite schema-sync harness because the repository contains PostgreSQL-specific migrations.
See the form and installer guides for remaining limitations. No new database migration is needed
for rule source metadata; existing pending migrations from previous PRs still must be applied.

## Español

v0.30.0 reúne el instalador inicial, formularios configurables, importación/exportación y
mediciones de pasos. Añade reglas de activación basadas en mediciones y una prueba de ejemplo
que usa la misma comparación que el servidor. Las reglas se conservan en cada ejecución y sus
decisiones se auditan. Un valor ausente nunca activa una rama de mediciones.

La vista previa no ejecuta el flujo ni aprueba QC. Las asignaciones y notificaciones automáticas,
las reglas generales y la creación de bucles quedan pendientes. Revise PostgreSQL, CI y navegador
antes de desplegar; esta versión no afirma estar validada para producción.
